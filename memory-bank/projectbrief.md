# Brainy React Native Project

## Project Overview
A React Native mobile application with a clean architecture structure, focusing on maintainability, scalability, and best practices.

## Core Requirements
- Clean Architecture implementation
- TypeScript support
- State management with Redux
- Navigation setup
- API integration layer
- Dependency injection
- Testing infrastructure
- Environment configuration
- Internationalization support

## Project Structure
```
src/
├── app/           # Application configuration and setup
├── core/          # Core utilities and shared components
├── data/          # Data layer (API calls, repositories)
├── di/            # Dependency injection setup
├── domain/        # Business logic and entities
└── presentation/  # UI components and screens
```

## Technical Stack
- React Native
- TypeScript
- Redux Toolkit
- React Navigation
- Axios
- Jest
- React Native Testing Library
